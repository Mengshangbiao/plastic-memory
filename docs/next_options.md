# 待选优化方案

以下为建议，尚未替换当前交互。当前版本保留独立编号选项、右键动作菜单和顺序动作列表。

## A. 撤销 / 重做与历史版本（建议优先）

增加 `Ctrl + Z`、`Ctrl + Shift + Z`，覆盖节点移动、删除、连线和对白改动。自动保存仍保留，另外提供按时间恢复的版本列表。

解决的问题：当前只能删除动作重新制作，误删节点后不能在界面中直接撤销。

代价：需要统一各编辑界面的操作记录，明确一次拖动、一次对白修改分别算一步。

## B. 在动作列表旁增加可拖动的时间轴

保留你设计的右键菜单，增加播放头、逐帧预览和各图层的动作条。拖动动作条调整时间，拖动播放头查看当时状态。

解决的问题：多个人物同时移动时，文字、语音、差分和音效的时机更容易观察与协调。

代价：需要为图层增加明确的开始时间与并行关系；第一版“每个图层按顺序、各图层同时开始”的逻辑会扩展。

## C. 导出独立游戏目录

“创建游戏”后增加“导出 Windows 游戏”，输出包含播放器、剧情和素材的完整目录，让没有安装创作工具的人也能游玩。

解决的问题：作品分享。现阶段作品只能从工具内的“纷乱回忆”打开。

代价：需要实现只含游玩界面的启动方式、素材完整性检查和打包流程。游玩存档也可在这一阶段补齐。

可以只选一项，也可指定顺序。例如：先 A，再 C，最后 B。
