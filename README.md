# 可塑性记忆 · 第一版 0.2

面向个人创作者的 Windows Galgame 创作工具。使用 Flutter + Dart，根据 2026 年 10 月 21 日提供的交互要求制作。

## 启动

构建后的程序位于 `build/windows/x64/runner/Release/plastic_memory.exe`。运行或复制时请保留同目录中的 DLL 和 `data` 文件夹。

开发环境：Flutter 3.47.5、Dart 3.13.4、Visual Studio 2022 的 C++ 桌面开发组件。

```powershell
flutter pub get
flutter run -d windows --no-pub
```

如果 Windows 未启用开发者模式，首次 `pub get` 可能提示缺少符号链接支持。依赖下载完成后，可在项目中建立 NTFS 目录联接并再次生成插件注册文件：

```powershell
.\tools\prepare_windows_plugins.ps1
flutter pub get --offline
flutter run -d windows --no-pub
```

此脚本只创建本项目的插件目录联接。

## 界面主题

当前使用“五彩斑斓的黑”与“流光”动效：近黑背景、深灰面板、4px 圆角和细描边。首页两张入口卡的流光沿边缘缓慢绕行，悬停或键盘聚焦时转为靛蓝或暖黄；设置与退出位于下方，底栏显示项目数、节点总数和最近修改时间。

流光默认 28 秒一圈，背景 40 秒明暗往返。两卡错开 80ms 入场，标题保持静止。背景同时显示至多一粒浮尘，两卡轮流突出一个尖端；另有短暂划过的流星，每批随机 1、3、5 或 8 颗，每颗随机取情绪色，两批起始时间相隔 8 或 12 秒。流星带 1px 渐隐拖尾，每颗持续约 0.65–0.95 秒，同批稍微错开出现。退出首页、最小化或系统要求减少动画时停止持续绘制。卡片右下方的“上次进入”读取 `entry-visits/*.json` 的文件修改时间，第一次进入前显示“尚未进入”，示例项目不会生成虚假的访问记录。

作品的颜色按项目 ID 固定映射。开幕、事件、选项、乱数、结局分别使用静、爱、思、惧、惘的颜色；选中节点会强调相邻连线。默认播放器对话框采用半透明近黑与背景模糊。已有自定义图片和故事内容继续使用原素材。

配色集中在 `lib/palette.dart`，公共控件主题在 `lib/ui.dart`，首页布局在 `lib/home_view.dart`，共享动效时钟与画笔在 `lib/home_flow.dart`。界面优先使用系统中的 Noto Sans SC，未安装时回退到微软雅黑；数字与状态标签使用 Consolas。

## 从首页开始

- **纷乱回忆**：游玩已创建的作品，首次启动包含一部示例故事。
- **创造回忆**：直接进入新项目画布，开幕位于画布中央。点击顶部作品名可以重命名；文件夹按钮可以打开以前的草稿或新建项目。
- **设置**：游戏总音量、人物音量、背景音乐、点击音与音效、文字速度、文字大小、全屏显示。保存后持久保留。
- **退出**：关闭程序；通过窗口关闭按钮退出时也会保存已经完成的项目编辑。

## 删除历史项目

- 删除创作草稿：进入“创造回忆”，点击顶部文件夹按钮“打开 / 新建项目”，再点项目右侧的垃圾桶。确认后删除该草稿、素材副本及保存备份；已有的可游玩版本会保留。
- 删除可游玩的作品：进入“纷乱回忆”，点击作品“游玩”按钮旁的垃圾桶。确认后删除该版本及其素材副本，创作草稿会保留。
- 删除前会显示项目名称和删除范围，可取消；确认删除后无法撤销。删除当前编辑项目会返回首页，列表和首页项目统计随之刷新。清空所有项目后，重新启动仍保持空列表。

原始导入文件不受影响。若要同时移除创作草稿与可游玩版本，请分别在上述两处删除。

## 创作流程

1. 右上角创建人物。点击人物标签可以重命名，已有对白会同步更新。
2. 左下角“导入素材”打开七个分类：背景音、点击音、人物音、特殊音效、背景图、人物图、物品图。支持拖入或选择多个文件；音频可试听，图片可预览。
3. 从左上角拖入事件、选项、结局、乱数选择。可收起工具栏、项目操作和人物窗口，再通过对应图标恢复。
4. 悬停或选中节点后，四边出现连接点。拖动连接点建立箭头；也可依次点击两个连接点，或在右下角选择目标节点。右下角可删除已有连线。
5. 双击事件或结局编写对白。选择人物后输入文本，**Enter** 完成一段，**Shift + Enter** 换行；再选择下个人物继续。点击“结束文本编写”后可集中编辑演出。
6. 双击对白，或点击电影图标，进入演出制作。右键对白可修改人物、文本、语音、音乐、文字速度和字号。
7. 通过“测试运行”检查分支与演出；退出试玩直接回到编辑器。
8. “创建游戏”检查流程并生成独立于草稿的作品快照，在“纷乱回忆”中游玩。“保存并退出”保存草稿并回到首页。

编辑器在已完成的操作停止两秒后自动保存，也支持 `Ctrl + S`。尚未按 Enter 或点击确认的输入不算已完成编辑。

## 节点与选项

| 节点 | 连接规则与编辑方式 |
| --- | --- |
| 开幕 | 一个出口，只能连接事件或乱数。双击制作开幕画面；右键图片可设置“开始故事”或“退出作品”事件。未设置图片开始按钮时显示默认按钮。 |
| 事件 | 可连接一个其他节点，包括回到开幕；或连接多个同级选项。两种方式不能混用。双击编辑对白；右键设置背景、模糊、整段音乐和点击音。 |
| 选项 | 每个方块对应一个永久编号。方块标题是可点击的选项文本；双击编辑同级选项共用的提示文本。右键设置出现条件，要求所选编号全部已被选过。一个选项连接一个后续节点。 |
| 乱数选择 | 至少连接两个事件；每次经过时等概率随机选择一个。 |
| 结局 | 只能被连接；对白结束后自动回到开幕，并开始新一轮选择记录。 |

选项出现时保留上一段演出的结束画面。缺少目标或所有选项条件均不满足时，播放器提供返回编辑器或开幕的入口。

“创建游戏”会检查断线、无效条件、孤立节点、出口规则和无法到达结局的路线。复杂条件组合仍应逐条试玩。

## 演出与声音

- 人物图、背景图、物品图可以拖到场景，或点击添加。拖动图片调整位置，拖动四角调整宽高。
- **变化**：以图片上一动作的结束状态为锚点，移动或缩放到终态，保存后填写时间和同步音效。
- **隐藏**：在指定时间内渐变到目标透明度；也可恢复为不透明。
- **初始透明度**：设置图片开始显示时的透明度。
- **差分**：动作开始时替换图片，持续设定的时间后进入下一动作。
- 每张图片的动作按列表顺序执行，可以上下调整或删除；不同图片同时开始执行。场景编辑器支持动作预览，音效通过“测试运行”验证。
- 每段对白默认延续当前音乐；指定单句音乐时覆盖整段设置，也可以明确停止音乐。没有音乐可延续时保持安静。
- 未单独制作演出的对白延续上一场景。右键对白可清除该句演出，恢复继承。
- 顶部调色盘按钮可以替换公用对话框和选项按钮图片；界面素材可先导入“物品图”。

图片导入：PNG、JPEG、WebP、BMP。音频导入：MP3、WAV、OGG、M4A、FLAC；能否解码取决于 Windows 原生播放器支持，遇到不能播放的文件可转为 WAV 或 MP3。

## 本地文件

具体位置见“设置 → 项目存放位置”。目录结构：

```text
MemoryStudio/
  settings.json
  projects/<项目编号>/
    project.json
    project.json.bak
    assets/{bgm,click,voice,sound,background,character,item}/
  games/<项目编号>/
    project.json
    assets/...
```

素材按分类复制，导入同名文件不会覆盖。保存时先写临时文件，再替换项目文件，并保留上一版备份。创建游戏时复制项目与素材，随后修改草稿不会改变作品库中的完成版本；再次创建会更新该作品版本。损坏的项目不会自动覆盖，其他项目仍然可以打开。

## 第一版边界

本轮目标是 Windows 桌面端。`web` 仍是原项目的占位目录，尚未适配这一版的本地文件与原生窗口功能。

“创建游戏”目前生成工具内可游玩的作品及素材快照，尚未提供独立游戏 EXE 打包。游玩存档、自动播放、已读跳过、撤销/重做、关键帧时间轴、人物差分套组和素材裁剪尚未实现。

后续可选改进见 [待选优化方案](docs/next_options.md)，这些交互改动需要选择后再制作。
