# 流光主题验证 · 2026-10-25

首页按「动效规格 · 流光」改造，保留已有深色主题和功能入口。

## 动效参数与取舍

- 两卡共享一个 Ticker，画笔更新限于每秒最多 30 次；标题、正文与静态底图分别隔离绘制。
- 流光路径为 1px 圆角描边，默认 28 秒一圈，方向相反；拖尾占周长 18%，静止情绪色饱和度压至 20%，颜色集中在尖端。
- 悬停 / 键盘聚焦：纷乱回忆为靛蓝、12 秒一圈；创造回忆为暖黄、10 秒一圈。原规格只给出“快一档”，这里将其具体化为 10 秒。换色 300ms，离开后 600ms 恢复；采用指定的 Cubic(.4, 0, .2, 1)，速度积分保持光点位置连续。
- 两卡轮流拥有主亮点。鼠标跨卡或退出悬停时依次熄灭、点亮，避免第三处同时发亮；其他卡片仅保留很淡的中性拖尾。
- 40 秒正弦往返的底色范围为 `#07080A` 到 `#090A0D`。按最终 8 位色值变化更新底图，避免每帧重绘全屏渐变。
- 浮尘采用固定种子，4–6 秒生成一次，生命 8–12 秒，上升 40–60px，横漂 ±8px，大小 1–2px，白色为主、15% 概率取情绪色。粒子池上限 12，同时只绘制一粒；浮尘与卡片继续遵守原来的亮点限制。
- 按后续要求增加流星：每批等概率选择 1、3、5 或 8 颗，批次起始间隔等概率选择 8 或 12 秒，每颗独立随机取八种情绪色。正式运行使用新的随机序列，测试可指定种子。每颗持续 650–950ms，同批错开至多 290ms，向左下划过，尾部为 1px 渐变线，不使用大面积模糊。流星批次按本次明确要求独立于原来的“两处亮点”上限。
- 流星与浮尘共用背景画笔和首页时钟，不新增计时器；退出页面或隐藏时暂停，系统要求减少动画时清空流星。过期批次不会补播。
- 卡片以 400ms 淡入并上移 8px，两卡间隔 80ms；描边流光在 1.2 秒内展开，标题不参与入场。
- 可见但未聚焦的桌面窗口继续播放；切换页面、隐藏、最小化时停止时间推进。系统要求减少动画时展示静态页面，同时保留键盘聚焦描边。

访问痕迹保存在独立的 `MemoryStudio/entry-visits/library.json` 与 `creation.json`，显示值读取实际文件 mtime。第一次进入前显示“尚未进入”，进入后即使未修改项目也有记录。项目自动保存和示例创建不会伪造访问时间。访问记录读取失败不会阻止打开项目。

## 验证结果

- `flutter analyze --no-pub`：通过，无问题。
- `flutter test --no-pub`：30 项通过。新增测试模拟 20 分钟，观察到全部四种流星数量、两种间隔和八种情绪色；另外检查轨迹、淡出、清理、减少动画、跳过过期批次，以及无浮尘时仍正常绘制流星。原有悬停、描边、存储和页面测试继续通过。
- `flutter test integration_test/home_flow_test.dart -d windows --no-pub`：通过，录制 14.260 秒，流光移动约 0.5101 圈，实录捕捉到一批单颗流星；检查 1280×800、1920×1080、两入口悬停与返回后的真实访问提示。四种批量的随机规则由确定性测试覆盖。
- `flutter test integration_test/studio_test.dart -d windows --no-pub`：流光基础版已通过，原有编辑、素材导入、演出、播放、保存、原生音频与全屏流程正常。本次流星增补未重跑该套完整创作流程。
- `flutter build windows --release --no-pub`：最终发布版编译成功。
- 加入流星后的发布版首页性能：本机 24 个逻辑处理器，预热后实际采样 30.020 秒，进程使用 7.7812 CPU 秒；整机口径平均 **1.080%**，满足 <2% 的目标。等效单核口径为 25.92%，峰值工作集 130.5MB。该结果是本机实测，不保证其他硬件得到相同数值。

- `build/qa/flow/frames.json`：每帧时间、动画时钟、运行状态、可见流星数量与绕行比例。
- `build/qa/flow/home-1280x800.png`、`home-1920x1080.png`：精确客户端尺寸截图；同目录含灰度版本。
- `build/qa/flow/hover-library.png`、`hover-creation.png`、`home-after-visit.png`：悬停与访问记录截图。
- `build/qa/flow/visual-metrics.json`：彩色强调像素的检查结果。判据为 HSV 饱和度 >15%、明度 >20%，排除接近黑色的背景色偏；彩色强调面积约 0.1%，低于 5%。
- `tools/profile_home.ps1`：启动发布版，预热 5 秒后采样 30 秒进程 CPU，随后关闭这次启动的窗口；结果写入 `build/qa/flow/performance.json`。

CPU 数值按本机逻辑处理器数量折算为整机百分比，同时保留单核口径，以便在不同机器上复查。
